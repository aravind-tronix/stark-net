# STARK-NET

**A development-stage status board for a personal AI roster** — built on [Hermes](https://hermes-agent.nousresearch.com), reasoning across a **Claude** and **Grok** MCP roadmap.

Single-page dashboard tracking four Stark-lab-named AI units and the build progress of their Model Context Protocol integrations. Editorial-brutalist design in an Iron Man palette.

## The Roster

| Unit | Role | Stage |
|------|------|-------|
| **JARVIS** | Flagship agent — coding, systems, research, automation | Live |
| **EDITH** | Knowledge agent — long memory, curated knowledge base | Live |
| **FRIDAY** | Mobile workstation — remote worker node over secure mesh | Edge node |
| **DUMMY** | Lab robotics — physical helper via custom control SDK | Hardware |

## MCP Roadmap

Three parallel tracks — **Hermes Core**, **Claude MCP**, **Grok MCP** — with per-stage status (shipped / in-progress / planned).

## Stack

Hermes runtime · Claude + Grok dual-provider brains · shared persistent memory + holographic fact store · secure private mesh · robotics SDK bridge · self-curating skills engine.

## Run

Pure static HTML — no build step.

```bash
# open directly
xdg-open index.html
# or serve
python3 -m http.server 8080
```

## Privacy

Public-facing by design. No credentials, tokens, network addresses, personal identifiers or private data appear anywhere in this repo — only roles and capabilities.
